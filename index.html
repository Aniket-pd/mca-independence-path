    An unofficial hackathon prototype. It does not connect to or represent the Ministry of Corporate Affairs.

    Change language

    Accessibility statement

    This prototype was designed with reference to GIGW 3.0 and WCAG 2.1 Level AA. This is a design claim, not formal certification.

    Implemented functionality

    • Semantic landmarks, headings and native controls
    • Keyboard navigation, visible focus and skip navigation
    • Programmatic labels, instructions, errors and status announcements
    • Accessible HTML documents, upload extraction and structured review
    • Responsive reflow, text enlargement and bilingual accessibility content

    Mocked MCA/government integrations

    Identity verification, OTP delivery, name availability, document extraction, digital signature, payment, submission and certificate generation are simulated. No data leaves this page.

    Known limitations

    Automated and manual checks are part of this prototype review, but formal testing with every browser, device and assistive technology has not been completed.
