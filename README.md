# MCA Independence Lane

An accessible, bilingual prototype showing how a blind entrepreneur can complete a synthetic company-registration filing independently.

Live project: [mca-independence-path.aniket-pd.chatgpt.site](https://mca-independence-path.aniket-pd.chatgpt.site)

## Run locally

This repository contains a static export of the published project. Start any static web server from the repository root, for example:

```sh
npm run dev
```

Then open `http://localhost:4173`.

## Notes

- English and Hindi are supported.
- The interface is designed for keyboard and screen-reader use.
- This is an unofficial prototype and does not submit information to India's Ministry of Corporate Affairs.
